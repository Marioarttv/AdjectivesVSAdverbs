# Adjectives vs Adverbs - Unterrichtspräsentation

## Klasse 7 Realschule - Englisch

Diese interaktive HTML-Präsentation begleitet den Unterrichtsentwurf zum Thema "Adjectives and Adverbs" nach dem 5-Phasen-Modell von Ziegesar.

## 📖 Verwendung

### Die Präsentation öffnen:
1. Öffnen Sie die Datei `presentation.html` in einem modernen Webbrowser (Chrome, Firefox, Safari, Edge)
2. Drücken Sie **F11** für den Vollbildmodus (empfohlen)

### Navigation:
- **Pfeiltaste rechts** oder **Leertaste**: Nächste Folie
- **Pfeiltaste links**: Vorherige Folie
- **ESC**: Übersicht aller Folien
- **S**: Speaker-Notizen (nicht implementiert, da mündliche Durchführung)
- **F**: Vollbildmodus

## 📊 Aufbau der Präsentation

Die Präsentation folgt den 5 Phasen des Unterrichtsentwurfs:

### 1️⃣ **Phase 1: Demonstration (Folien 2-5)**
- Einführung durch Tierbeispiele (Schildkröte, Gepard)
- Kontextuelle Präsentation von Adjektiven und Adverbien
- Visuelle Unterstützung mit Emojis

### 2️⃣ **Phase 2: Verstehen und Reagieren (Folien 6-10)**
- Erklärung: Was sind Adjektive?
- Erklärung: Was sind Adverbien?
- Show-me-Activity
- Gegenüberstellung

### 3️⃣ **Phase 3: Reproduzieren (Folien 11-14)**
- Bildungsregel: Adjective + -ly = Adverb
- Gemeinsames Üben (Choral Repetition)
- Lückentextübungen

### 4️⃣ **Phase 4: Bewusstmachung (Folien 15-20)**
- Anchor Chart mit Grammatikregeln
- Bildungsregel visualisiert
- Unregelmäßige Formen (good → well, fast → fast)
- Position im Satz
- Merkhilfen

### 5️⃣ **Phase 5: Produzieren (Folien 21-24)**
- Partnerarbeit: "Describe Your Day"
- Sentence Frames als Hilfestellung
- Zusätzliche Übungen

### 📝 **Abschluss (Folien 25-30)**
- Exit Ticket
- Hausaufgaben
- Zusammenfassung
- Referenzfolie (zum Ausdrucken)

## 🎨 Farbcodierung

Die Präsentation verwendet durchgängig das Farbsystem aus dem Unterrichtsentwurf:

- 🟢 **GRÜN**: Adjektive (mit hellgrünem Hintergrund)
- 🔵 **BLAU**: Adverbien (mit hellblauem Hintergrund)

## ✨ Besondere Features

### Visuelle Gestaltung:
- Klare Farbcodierung für besseres Verständnis
- Große Schrift für gute Lesbarkeit
- Emoji-Platzhalter für Bilder (können durch echte Bilder ersetzt werden)
- Responsive Design für verschiedene Bildschirmgrößen

### Differenzierung:
- Verschiedene Schwierigkeitsstufen bei Übungen
- Sentence Frames für schwächere Schüler
- Offene Aufgaben für stärkere Schüler

### Interaktive Elemente:
- Show-me-Activity Folien
- Übungsfolien mit Lückentexten
- Exit Ticket zur Lernstandskontrolle

## 🖼️ Bilder anpassen (optional)

Die Präsentation verwendet derzeit Emoji-Platzhalter. Um echte Bilder einzufügen:

1. Laden Sie Bilder herunter (z.B. von Pixabay, Unsplash - lizenzfrei)
2. Speichern Sie die Bilder im Projektordner
3. Öffnen Sie `presentation.html` in einem Texteditor
4. Ersetzen Sie die `.image-placeholder` divs durch `<img src="bildname.jpg">` Tags

Empfohlene Bilder:
- 🐢 Schildkröte (langsam, grün)
- 🐆 Gepard (schnell, beim Rennen)
- 🎤 Singendes Mädchen (glücklich)
- 📚 Nervöser Schüler

## 📱 Präsentationsmodus

### Für die Projektion im Klassenraum:
1. Verbinden Sie den Laptop mit dem Beamer
2. Öffnen Sie die Präsentation im Browser
3. Drücken Sie F11 für Vollbild
4. Nutzen Sie die Pfeiltasten zur Navigation

### Für Schüler zum Nacharbeiten:
Die HTML-Datei kann auch den Schülern zur Verfügung gestellt werden (z.B. über Moodle, Teams, als Download)

## 📋 Begleitende Materialien

Für den vollständigen Unterricht werden zusätzlich benötigt:
- Differenzierte Arbeitsblätter (A, B, C)
- Exit Tickets (ausgedruckt)
- Anchor Chart Poster für den Klassenraum
- Wortkarten für Matching-Activity

## 💡 Tipps für die Durchführung

1. **Zeitmanagement**: Die Präsentation hat 30 Folien - nutzen Sie nicht alle in einer 45-Minuten-Stunde. Wählen Sie gezielt aus.

2. **Interaktion**: Stoppen Sie regelmäßig für Schülerbeiträge und Übungen

3. **Differenzierung**: Nutzen Sie die verschiedenen Übungsfolien je nach Klassenstärke

4. **Anchor Chart**: Folie 15 kann als Vorlage für das Klassenplakat dienen

5. **Referenzfolie**: Folie 29 kann ausgedruckt und laminiert werden als persönliche Lernhilfe für Schüler
