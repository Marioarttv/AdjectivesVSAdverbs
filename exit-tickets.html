📋 Anleitung für Lehrkräfte

Differenzierte Exit Tickets: Wählen Sie die passende Version für jeden Schüler basierend auf dem Leistungsniveau.

  • Version A (Grün): Für schwächere SuS - Markierungsaufgabe mit visueller Unterstützung
  • Version B (Gelb): Für mittlere SuS - Lückentext mit Wortauswahl
  • Version C (Rot): Für stärkere SuS - Freie Satzproduktion

Tipp: Drucken Sie auf farbigem Papier entsprechend dem Niveau (grün/gelb/rot) für einfache Sortierung!
